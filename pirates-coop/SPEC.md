# 팀플호에 해적이 탔다 — 협동 항해판 (SPEC, 모든 작업의 단일 기준)
마감 03:22 UTC. 기반: projectx-tv/app/index.html(오디오 엔진·루프 배경·결말 영상 구조) + teamplay-pirates(해적 세계관 그림·영상).
## 규칙
- 10~20명, 3팀(팀당 3~7명) = 배 3척. 노트북+TV, 준비물 종이 1장(팀별 쪽지).
- **팀마다 각자 X맨 1명**(해적 스파이). 각 팀이 종이를 사람 수만큼 찢어 한 장에만 X를 쓰고 접어 섞어 한 장씩 뽑는다(진행자도 모름).
- 모든 라운드는 **팀 안에서 협동**하는 게임. X맨은 매 라운드 **고의로 슬쩍 방해**(대놓고 X, 규칙 위반 X, "내가 X맨" 말하기 X). 다른 두 팀은 관객이자 감시단.
- 라운드 이름 유지 + 항해 테마 부제:
  - 1R 자료조사 — 「출항 전 자료조사」 미니게임 **항해일지 귓속말 전달**(외부 원형: 귓속말 전달/전언 게임)
  - 2R 팀 회의 — 「갑판 집합」 **말 없이 줄서기**(생일 순, 비언어 아이스브레이커)
  - 3R PPT 제작 — 「찢어진 돛 수리」 **스피드 퀴즈 유지**, 단어는 쉽게(배·바다·수리·발표 소재의 쉬운 일상어, ★=수리 부품 2점)
  - 4R 최종 발표 — 「입항 보고」 **한 단어씩 이어 말하기**(원 워드 스토리 즉흥극)
- 점수: 라운드마다 팀 0~10점. R1=맞춘 항목 수×2(항목 5개). R2=round(10×제자리 선 인원/팀 인원). R3=min(10, round(원점수×0.7)) (원점수: 일반 단어 1점, ★ 2점). R4=다른 두 팀이 손가락 1~5점씩 준 합(2~10).
- 마지막: 추리 토론 60초 → "삼 이 일 지목!" 팀원 전원이 자기 배의 X맨이라 생각하는 사람을 동시에 가리킴 → 최다 지목자가 쪽지 공개 → 진행자가 팀마다 **검거/놓침** 입력. 검거 +10, 놓침 −5.
- 총점=R1~R4 합(최대 40)+검거 보너스. 순위 표시. **결말은 검거한 팀 수로 결정**: 0팀=「해적단 승리」(e1), 1~2팀=「아슬아슬한 입항」(e2), 3팀=「완벽한 입항」(e3).
- X맨의 수법(규칙 화면에 공개, 모두 알아도 됨): R1 숫자·단어 한 글자를 슬쩍 바꿔 전달 / R2 틀린 자리로 유도하는 손짓·일부러 늦게 서기 / R3 엉뚱한 답 외치기·★ 단어 패스 유도 / R4 문장을 엉뚱하게 비트는 한 단어.
- 진행자 2명: A(마이크·타이머 신호) B(노트북 조작·입력). 45분이 아니라 **약 40분**: 오프닝 2·비밀 쪽지 3·규칙 3·R1 8·R2 6·R3 9·R4 6·추리/지목 3.
## 앱 화면 흐름 (STEPS)
setup → intro(영상) → secret → rules(3장) → r1 → r2 → r3 → r4 → vote(추리토론·지목·공개) → end(결말 영상·최종 점수)
- r1: 안내(나레이션→캡틴F 한마디) → 계획 30초 타이머 → 항해일지 TV 공개 10초(첫 사람만 봄) → 전달 60초 타이머 → 확인(정답 일지 표시 + 팀별 맞춘 항목 0~5 입력) → 결과. 항해일지 풀 4개(항목 5개, 각각 "항목 값" 형식 쉬운 숫자·단어, 예: 쌀 12포대, 물 40통, 출항 새벽 5시, 목적지 종강항, 창고 3번).
- r2: 안내 → "삼 이 일 시작!" 카운트다운 → 말 금지 60초 타이머 → 확인(팀마다 "제자리에 선 사람 수" 0~팀인원 입력) → 결과.
- r3: 기존 스피드 퀴즈 코드 유지(팀 순서대로, 90초, 정답/패스/그만). 단어 풀을 쉬운 단어로 교체(아래). 결과 화면에 raw와 환산 점수.
- r4: 안내 → 팀 순서대로 주제 공개(풀: 우리 배의 항해 보고, 학식 줄 해결책, 종강항 도착 계획, 선장님께 올리는 건의) → 40초 이어 말하기 타이머 → 다른 두 팀 1~5점 입력 → 다음 팀.
- vote: 단서판(라운드별 팀 점수·가장 점수가 떨어진 라운드) + 추리 토론 60초 → 지목 카운트다운 → 팀별 검거/놓침 입력 → 공개 연출.
- 오디오: projectx-tv의 소리 엔진(공용 오디오 요소 잠금 해제, 음악 3종 교체·덕킹, 소리/음악 토글, 소리 켜기 안내)을 그대로 사용. 음악 매핑: setup·rules·결과=calm, 미니게임 진행 중=play, secret·추리·지목·공개=tense, intro·결말 영상=무음.
