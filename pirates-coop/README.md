# 팀플호에 해적이 탔다 — 협동 항해판

3팀(팀당 3~7명, 12명이면 4·4·4) = 배 3척. 팀마다 **해적 스파이(X맨) 1명**이 숨어 있고, 4개 협동 게임(귓속말 전달 · 몸으로 말해요 · 망원경 이미지 퀴즈 · 대본 외워 말하기)을 하면서 슬쩍 방해하는 X맨을 추리하는 약 40~43분짜리 TV 진행형 게임. 결말은 6가지(해적단 완승 · 해적단 승리 · 한 척의 생존 · 아슬아슬한 입항 · 완벽한 입항 · 전설의 항해).

## 먼저 읽을 것
| 문서 | 내용 |
|---|---|
| `RULES.md` | 진행자용 규칙서(역할 · 진행표 · 라운드별 규칙 · 점수 · 결말 · FAQ) |
| `SOURCES.md` | 게임 원형이 된 외부 자료, 실제로 열어 본 페이지, 우리가 바꾼 것 |
| `SPEC.md` | 앱·에셋·점수 공식의 단일 기준(개발용) |

## 실행
- **온라인**: https://claude.ai/artifact/QKU6cnSYYfw42HAMM7cUZG (비공개 — 공유 메뉴에서 열람자 추가) — TV에 연결한 노트북의 크롬에서 연다. 처음 한 번 화면을 클릭해야 소리가 난다.
- **오프라인**: `projectx-tv/build_offline.py`와 같은 방식으로 `app/`을 한 파일로 감싸 인터넷 없이 여는 것을 목표로 한다. `[미확인]` 이 폴더용 오프라인 빌드는 이 문서를 쓰는 시점에 만들어지지 않았다 — 앱 완성 후 별도 확인.
- **준비물**: 종이 1장(쪽지용), 노트북 + TV, 진행자 2명(A: 마이크·판정 / B: 노트북 조작·입력).

## 조작
앱 조작(다음/이전 · 키보드 · 타이머 · 점수 입력)은 `projectx-tv`와 같은 구조로 만들 예정이다. `[미검증]` 실제 키 배치와 버튼은 앱이 완성된 뒤 이 항목을 갱신해야 한다.

## 만든 방식
- 영상 · 그림 · 음성: Higgsfield(이미지 · 영상) · TTS(minimax) — 이전 TV판과 같은 파이프라인 재사용. 구체적인 사용량과 비용은 완료 보고에 따로 적는다.
- 게임 규칙: 1R 귓속말 전달은 외부 아이스브레이커를 조사해 우리 구조(팀 내부 협동 + X맨 방해)로 개조했다. 2R 몸으로 말해요와 4R 대본 외워 말하기는 사용자 지시로 새로 바꾼 것이며, 이 둘은 외부 조사를 새로 하지 않았다 `[미검증]`. 처음 조사했던 줄서기·한 단어 이어 말하기 원형의 기록은 `SOURCES.md`에 참고용으로 남겼다.
- 3R 망원경 이미지 퀴즈의 그림 30장은 Higgsfield(seedream)로 새로 생성했다. 스피드 퀴즈와 삼육구 게임은 최종 구성에서 뺐다.

## 한계 · 미검증
- X맨이 들키는 정도, 점수 밸런스는 실제 플레이로 검증하지 않았다(`RULES.md` 밸런스 메모).
- 외부 게임 조사는 페이지 일부 문단 기준이고, 한 곳(scouts.org.uk)은 403으로 열지 못했다.
- 음성과 BGM은 소리를 직접 듣지 않고 받아쓰기 · 음량 측정으로만 확인한다. 행사 전 한 번 끝까지 틀어 볼 것.
- 이 폴더는 아직 커밋 · 배포 전이다.
