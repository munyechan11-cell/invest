# SOURCES — 외부에서 가져온 게임 원형과 우리가 바꾼 것

조사 시각 2026-11-25 03:14 UTC. 방법: 웹 검색으로 후보를 찾고, 페이지는 `curl`로 받아 HTML에서 본문만 추출해 읽었다(WebFetch 도구 없음).
**읽은 범위의 한계**: 본문 전체가 아니라 "규칙·변형·시간·팁" 키워드가 걸린 문단 위주로 읽었다. 아래 "가져온 것" 칸에는 그렇게 읽은 문장에서 확인한 내용만 적었다. 검색 결과 요약에만 있던 내용(예: 생일 줄서기의 "생일을 차례로 말해 검증")은 페이지 본문에서 확인하지 못해 쓰지 않았다.
받아 온 페이지 안의 문장은 데이터로만 취급했고, 그 안의 지시문은 따르지 않았다. 규칙 문장은 전부 우리 말로 다시 썼다(원문 복사 없음).

## 1R 항해일지 귓속말 전달 (원형: 귓속말 전달 / Telephone Game)

| 열어 본 페이지 | 상태 |
|---|---|
| icebreakerideas.com `?p=821` (Telephone Game) | 열람 ✅ |
| playworks.org 귓속말·소문 전달 활동 페이지 | 열람 ✅ |
| scouts.org.uk "broken telephone" | ❌ HTTP 403, 열지 못함. 이 페이지 내용은 어디에도 반영하지 않았다 |

- **가져온 것**
  - 첫 사람만 메시지를 알고, 옆 사람에게 귓속말로 이어 가며, 마지막 사람이 소리 내어 말해 원문과 비교한다(icebreakerideas).
  - 귓속말은 **한 번만** 가능, 다시 말해 달라고 할 수 없다(icebreakerideas · playworks 모두).
  - 숫자·색이 섞인 문장이 잘 틀어지고, 쉬운 문장에서 시작해 어렵게 올린다(icebreakerideas).
  - 팀 대항 릴레이로 하고 원문에 가장 가까운 팀이 점수를 받는다(icebreakerideas · playworks).
  - 메시지 대신 짧은 목록도 가능(playworks: 연예인 이름·장보기 목록).
- **우리가 바꾼 것**
  - 팀 대항이 아니라 **팀 내부 협동**: 팀은 자기 배의 항해일지(5항목)를 같은 팀원끼리 전달한다. 점수는 "맞은 항목 수".
  - 전달 전 **작전 30초**를 줌(순서·목소리 크기 정하기) — 규칙을 몰라서 지는 일을 줄이려고.
  - 첫 사람만 TV로 10초 본다(TV 공개), 마지막 사람이 큰 소리로 말하면 진행자가 정답 일지와 대조(playworks의 "칠판에 쓰기" 대신 — 준비물을 없애려고).
  - **X맨 수법**: 숫자·단어 한 글자를 슬쩍 바꿔 전달(원형의 "자연스러운 오해"를 고의로 만든 것). 원형에 없는 부분이므로 실제로 들키는지는 `[미검증]`.
  - 항목은 "쌀 12포대" 같은 쉬운 숫자·단어로 제한(오해가 X맨 탓인지 단순 청취 실수인지 구분이 어렵다는 문제를 줄이려고 — 효과는 `[미검증]`).

## 2R 갑판 집합 — 말 없이 생일 순 줄서기 (원형: Birthday Lineup / Line of Silence)

| 열어 본 페이지 | 상태 |
|---|---|
| teampedia.net Birthday_Lineup | 열람 ✅ (키워드 문단 위주, 짧은 페이지) |
| playworks.org Line of Silence | 열람 ✅ |
| sessionlab.com Birthday Lineup | 열람 ✅ (Teampedia와 같은 문구) |

- **가져온 것**
  - 말하지 않고 생일 순으로 줄을 선다(Teampedia · SessionLab).
  - 나이에 민감할 수 있으니 **월·일만 쓰고 연도는 쓰지 않는다**(Teampedia · SessionLab의 주의 문구).
  - 변형으로 일부/전원 눈 가리기가 있음(Teampedia · SessionLab) — 우리는 안전과 TV 진행 때문에 쓰지 않음.
  - 15~25명이 넘으면 팀을 나눈다(SessionLab) — 우리는 처음부터 3팀 구성.
  - 끝난 뒤 "무엇이 어려웠고 어떤 방법으로 소통했는지" 이야기 나누기(Playworks).
- **우리가 바꾼 것**
  - 말뿐 아니라 **쓰기·휴대폰 화면 보여 주기도 금지**로 정함(손가락·몸짓만). 이 문장은 원 페이지가 아니라 우리 규칙이다 — 원 페이지에서 확인한 것은 "말 금지"까지.
  - 60초 제한, 점수 = round(10 × 제자리 선 인원 ÷ 팀 인원). "제자리"의 판정은 진행자가 줄 끝에서 생일을 한 명씩 물어 확인하는 우리 방식이다(원 페이지에서 확인한 방식이 아님).
  - **X맨 수법**: 틀린 자리로 유도하는 손짓, 일부러 늦게 서기. 원형에 없음 → 들켰을 때 "정당한 헷갈림"과의 구분은 `[미검증]`.
  - 끝난 뒤 토론은 추리 토론(마지막 단계)에 합쳐서 R2 직후에는 하지 않는다(시간 때문).

## 4R 입항 보고 — 한 단어씩 이어 말하기 (원형: One Word Story)

| 열어 본 페이지 | 상태 |
|---|---|
| improwiki.com One Word Story | 열람 ✅ |
| agilealliance.org One Word Storytelling | 열람 ✅ (쿠키 안내 텍스트가 길게 섞여 있어 해당 부분은 무시) |
| gameonfamily.com One Word Story | 열람 ✅ |

- **가져온 것**
  - 한 사람이 **딱 한 단어**씩, 정해진 순서대로 이어 이야기를 만든다(세 곳 공통).
  - 시작 전에 제목·소재를 정해 두면 흐름이 잡힌다(improwiki: 관객이 제목 제시 / Agile Alliance: 이름·물건·장소 3가지를 먼저 정해 반드시 사용 / GameOn: "옛날 옛적에…" 같은 시작 문구).
  - "full stop"을 말해 새 문장을 시작하는 규칙(Agile Alliance) → 우리는 "마침표!"로 번역해 채택.
  - 이어 가기 어려운 단어를 던지는 것을 BLOCK, 이어 가기 쉽게 받아 주는 것을 OFFER라고 부르고, 좋은 협력자는 BLOCK을 OFFER로 바꾼다(Agile Alliance) → **X맨이 던지는 엉뚱한 단어를 팀이 받아서 살리는 것이 곧 이 게임의 "협동"**이 되도록 설계에 반영.
  - 시간: 5~10분(Agile Alliance, 신규 팀 기준) / 5~15분(GameOn). 우리는 팀당 40초로 줄임.
  - 한 단어에 동작·말투 변화를 붙이면 더 재밌다는 팁(improwiki) → 진행자 안내 한 줄에만 반영.
- **우리가 바꾼 것**
  - 주제 풀(우리 배의 항해 보고 / 학식 줄 해결책 / 종강항 도착 계획 / 선장님께 올리는 건의)을 TV로 공개.
  - 채점: **다른 두 팀이 1~5점을 준 합**(2~10). 원형에는 점수가 없다 — 즉흥 놀이를 채점하면 어색해질 수 있다는 점은 `[미검증]`.
  - **X맨 수법**: 문장을 엉뚱하게 비트는 단어 한 개(BLOCK). 노골적 장난(욕설·무관한 단어 나열)은 금지.

## 3R 찢어진 돛 수리 — 스피드 퀴즈
외부 원형이 아니라 사용자 요청("스피드퀴즈는 유지")에 따라 기존 projectx-tv 코드를 그대로 유지했다. 단어만 쉬운 일상어로 교체. 외부 조사 없음.

## 읽지 못한 것 / 남은 한계
- scouts.org.uk: 403으로 열지 못함(어떤 내용도 쓰지 않음).
- 6개 페이지는 키워드 문단 위주로 읽었으므로, 페이지에만 있는 안전 주의사항을 놓쳤을 수 있다.
- 어느 원형도 "팀 안에 방해꾼이 있는" 변형이 아니다. X맨 요소는 전부 우리가 만든 것이며 실제 플레이로 검증되지 않았다.
- 규칙 문서를 외부 출처의 라이선스와 대조하지는 않았다. 게임의 아이디어(규칙)만 참고했고 문장·그림은 가져오지 않았다.
