# 팀플호에 해적이 탔다 — X맨을 찾아라

3개 조(조당 3~5명, 총 9~15명)가 40분 동안 하는 사회추리 게임. 조마다 배 한 척, 조마다 캡틴 F에게 매수된 해적(X맨)이 한 명씩 숨어 있다. 자료조사 → 미팅 → PPT 제작 → 최종 발표, 네 번의 "배 수리"를 버티고 마지막에 X맨을 지목한다.

## 구성물

| 경로 | 내용 |
|---|---|
| `app/index.html` + `app/assets/` | 진행 화면(프로젝터용) + 휴대폰 투표함(`#ballot`). 오프닝 영상 720p, 캡틴 F 방송 음성 9개, 일러스트 포함 |
| `print/teamplay-cards.pdf` | A4 7쪽: MC 큐시트 1 · 역할 카드 15장 · 수리 카드 18장 · 트롤 카드 18장 |
| `work/out/intro.srt` | 오프닝 영상 자막 원본 (자막은 영상에 번인되어 있음) |
| `work/script.json` | 내레이션·방송 대본, 사용한 TTS 엔진·보이스 |
| `work/assemble.py` 외 | 영상 합성·자막 타이밍·음성 정리 스크립트 (재생성용) |
| `build_offline.py` | `app/`을 인터넷 없이 여는 `offline/index.html`로 감싸는 빌드 스크립트 |

1080p 영상 원본(`intro_1080.mp4`, 50MB)은 용량 때문에 저장소에 넣지 않았다. 대화에서 받은 파일을 쓰거나 `work/assemble.py`로 다시 만든다.

## 실행

- **온라인**: 게시된 Artifact 링크를 프로젝터 노트북 크롬에서 연다. 휴대폰 투표함은 같은 링크 끝에 `#ballot`.
- **오프라인**: `python3 build_offline.py` → `offline/index.html`을 크롬으로 연다. 폰트는 인터넷이 없으면 시스템 한글 폰트로 대체된다.
- 조작: `다음 ▶` 또는 → / PageDown(클리커), `◀ 이전` 또는 ← / PageUp, `T` 타이머. 상단 `수정`으로 배마다 구멍 ±1 보정.
- 진행 기록은 그 브라우저에만 저장된다(새로고침해도 이어짐). `준비 → 새 게임`으로 초기화.

## 규칙 요약

- 진영: 조마다 해적 1, 4~5인 조는 항해사 1(게임 중 1번 팀원 역할 몰래 보기), 나머지 선원.
- 라운드: 캡틴 F 방송 → 회의 3분(조장이 작업자 지명) → 비밀 수리 1분(작업자가 카드 1장을 수리함에 엎어 넣기, 선원은 수리만) → 공개. 트롤 1장이라도 나오면 구멍 +1. 조장은 왼쪽으로.
- 작업자 수: 3명 조 2·2·2·2 / 4명 조 2·2·3·3 / 5명 조 2·3·3·4.
- 밀회(2R 뒤): 해적끼리 얼굴 확인, 폭풍 보낼 배 지정 → 그 배는 3R 실패 시 +2. 4R 최종 발표 실패는 모든 배 +2.
- 최후의 지목: 맞히면 −1, 틀리면 +1. 구멍 3개 이상 = 침몰(F). 침몰선 2척 이상이면 해적단 승리, 아니면 구멍이 가장 적은 조 우승.
- 준비 화면 › 규칙 조정에서 침몰 기준(2/3/4), 4R 배수, 폭풍, 시간을 바꿀 수 있다.

## 제작 방식

- 이미지(11장): Higgsfield `seedream_5_5`, 스타일 키 1장을 레퍼런스로 고정.
- 영상(10초 × 10블록): Higgsfield `minimax_h3` 2K, 블록당 5컷 지시. 실측 컷 수 4~5.
- TTS: Higgsfield `text2speech_v2`. 내레이터·캡틴 F 모두 minimax 엔진. 엔진 선택은 Whisper 받아쓰기 정확도로 비교해 결정했다(ElevenLabs는 "사흘"→"사월" 등 오인식, seed_speech는 발음 붕괴).
- 자막: 내레이션 파일별 Whisper 단어 타임스탬프에 맞춰 배치. 최종 영상에서 측정한 자막-음성 오차 최대 0.37초.

## 한계 · 미검증

- 게임 밸런스(해적 승률)는 실제 플레이로 검증하지 않았다. 해적이 너무 약하면 침몰 기준을 2로, 너무 강하면 4로.
- TTS 음색과 영상 배경음은 귀로 듣지 않고 받아쓰기·음량 측정으로만 확인했다. 행사 전 한 번 끝까지 틀어 볼 것.
- 휴대폰 투표함은 기기 간 동기화가 없다. 조마다 폰 1대를 돌려 쓰고, 결과(트롤 수)는 MC가 진행 화면에 입력한다.
