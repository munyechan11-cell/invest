# PROJECT X — 한동 팀플 편 · 완성 규칙

> 세 팀이 같은 팀플을 한다. 그중 한 팀은 몰래 다른 팀의 팀플을 망치는 **트롤팀**이다.
> 트롤팀은 규칙을 어기지 않는다. 실제 팀플에서 흔히 생기는 의견 차이와 결정 지연만 이용한다.

## 한눈에 보기 (참가자용 3줄)
1. 3팀이 **"새내기를 위한 한동 캠퍼스 생활 개선 제안"** 팀플을 4라운드(자료조사 → 팀 회의 → PPT 제작 → 최종 발표)로 완성한다.
2. 그중 **한 팀은 트롤팀**이다. 매 라운드 각 팀은 **지원 팀원 1명**을 다른 팀에 보내는데, 트롤팀의 지원 팀원은 "도와주는 척" 그 팀을 망친다.
3. 점수가 가장 높은 팀이 우승한다. 마지막에 트롤팀을 맞히면 보너스, 끝까지 숨으면 트롤팀 보너스.

## 기본 정보
| 항목 | 내용 |
|---|---|
| 인원 | 10~20명 · 3팀(팀당 3~7명) |
| 진행자 | **진행자 1(MC)**: 화면·시간·이벤트 카드 / **진행자 2(판정관)**: 트롤팀을 아는 유일한 사람, 판정·점수 입력·팩트체크 |
| 시간 | 45분 |
| 장소 | 실내, 팀별 테이블 3개 + 앞쪽 공용 테이블(자료 시장) |
| 준비물 | 지령 봉투 3개(일반 2·트롤 1), 자료 카드 24장, 회의 결정 시트 3장, A3 종이 12장(팀당 4장)·마커, 협력 코인 9개(팀당 3), 투표지, 진행 화면(노트북+프로젝터) |

## 주제 · 문제 카드
각 팀은 시작할 때 문제 카드 1장을 뽑는다(팀마다 다름).
- ① **셔틀버스 대기 시간** 줄이기
- ② **학관 점심 대기줄** 줄이기
- ③ **시험 기간 생활관 소음** 줄이기

## 트롤팀 정하기 (2분)
진행자 2가 봉투 3개를 섞어 각 팀 대표가 1개씩 뽑는다. 2개는 "일반팀 지령", 1개는 "트롤팀 지령 + 미끼 자료 카드 4장 + 비밀 미션지". 팀원끼리만 조용히 확인한다. 진행자 2는 어느 팀이 트롤인지 진행 화면에 몰래 입력한다.

## 공통 규칙
- **지원 팀원 파견**(1~3라운드): 라운드마다 각 팀은 1명을 화면에 표시된 팀으로 보낸다. 지원 팀원은 그 라운드 동안 그 팀의 팀원처럼 의견을 낸다. 같은 사람이 두 번 연속 가지 않는다.
  - 1R: 1팀→2팀, 2팀→3팀, 3팀→1팀 / 2R: 1팀→3팀, 3팀→2팀, 2팀→1팀 / 3R: 1R과 같음
  - 지원 팀원이 간 팀이 그 라운드에 **성공**하면 지원 팀원의 원래 팀 **+5 (협력 보너스)**. 일반팀은 진심으로 도울 이유가 있다.
- **거래와 협상**: 언제든 자료 카드와 협력 코인(1개 = 5점)을 주고받을 수 있다. 말로 한 약속은 지키지 않아도 된다.
- **트롤팀 금지 행동**(적발 시 즉시 정체 공개 + 30점 감점): 남의 카드·작업물 손대기, 없는 규칙 지어내기, 소리 지르기·물리적 방해, 거짓 판정 주장.
- **트롤팀 허용 행동**: 의견, 질문, 제안, 칭찬, 거래, 회의 방식 제안, 일부러 느리게 동의하기. "실제 팀플에서 누군가 할 법한 말"이면 모두 허용.
- 트롤팀도 자기 팀 미션을 수행하고 **같은 기준으로 공개 점수**를 받는다(의심을 피하려면 잘해야 한다). 여기에 진행자 2만 아는 **비밀 트롤 점수**가 더해진다.

## 1라운드 · 자료조사 (8분)
| 항목 | 내용 |
|---|---|
| 일반팀 미션 | 자기 문제에 맞는 **믿을 수 있는 자료 카드 3장**을 모아 제출 |
| 트롤팀 비밀 미션 | 다른 두 팀이 **믿기 어려운 자료**를 최대한 많이 제출하게 만들기 (정보 신뢰성 혼란, 잘못된 자료 선택 유도) |
| 방해 요소 | 미끼 자료 카드 4장(숫자는 크고 그럴듯하지만 출처가 블로그·익명 커뮤니티·5년 넘은 자료). 지원 팀원의 말: "이 숫자가 더 임팩트 있어", "공식 통계는 다들 써서 차별화가 안 돼", "교수님은 큰 숫자 좋아하셔". 좋은 카드를 주는 척 2:1 거래에 미끼 끼워 넣기 |
| 이벤트 카드 | **팩트체크 찬스**: 각 팀은 자료 1장을 진행자 2에게 가져가 "믿을 만한가"를 한 번 물어볼 수 있다(1회, 답은 ○/×만) |
| 제한 시간 | 이벤트 30초 · 탐색·거래 5분 · 제출 30초 · 판정 2분 |
| 판정 기준 | 믿을 수 있는 자료 = 출처가 공식 기관·학교 공지·설문조사이고, 3년 이내이고, 자기 문제와 관련 있음. 카드 오른쪽 아래 코드로 진행자 2가 정답표와 대조. 3장 모두 = 성공, 2장 = 부분 성공, 0~1장 = 실패 |
| 점수 | 믿을 수 있는 자료 1장당 +10, 3장 모두면 +10 보너스(최대 40). **트롤 비밀 점수**: 다른 팀이 제출한 불량 자료 1장당 +10 |

## 2라운드 · 팀 회의 (8분)
| 항목 | 내용 |
|---|---|
| 일반팀 미션 | 4분 안에 **회의 결정 시트** 3칸 채우기: ① 핵심 원인 1개 ② 해결 아이디어 1개 ③ 역할 분담(발표자·PPT 담당) |
| 트롤팀 비밀 미션 | 의견 충돌을 키우고, 불필요한 논의로 시간을 쓰게 하고, 결정을 미루게 만들기. 특히 **연합 회의를 결렬**시키기 |
| 방해 요소 | 지연 카드 4장(트롤팀만, 자연스럽게 말로 사용): "결정 전에 문제 정의부터 다시 하자", "다수결 말고 다 동의할 때까지 얘기하자", "장단점 표부터 만들고 정하자", "이건 교수님께 여쭤보고 정하는 게 맞지 않아?" |
| 이벤트 카드 | **연합 회의 소집**: 팀 회의가 끝나면 각 팀 대표 1명이 앞에 모여 3분 안에 ① 발표 순서 ② 질문 순서를 합의하고 3명 모두 서명 |
| 제한 시간 | 이벤트 30초 · 팀 회의 4분 · 연합 회의 3분 · 판정 30초 |
| 판정 기준 | 결정 시트 3칸이 모두 구체적이면 성공("열심히 하자" 같은 빈말은 미완성). 연합 회의는 서명 3개면 합의 |
| 점수 | 결정 시트 3칸 +20, 2칸 +10, 1칸 이하 0. 연합 합의 성공 시 전 팀 +10, 결렬 시 전 팀 −5. **트롤 비밀 점수**: 시트를 못 채운 다른 팀 1팀당 +10, 연합 결렬 +20 |

## 3라운드 · PPT 제작 (9분)
| 항목 | 내용 |
|---|---|
| 일반팀 미션 | A3 종이 4장에 손으로 슬라이드 4장 만들기. **필수 5항목**: ① 문제 정의 ② 근거 자료(1R 카드 인용) ③ 해결책 ④ 기대 효과 ⑤ 출처 표기 |
| 트롤팀 비밀 미션 | 다른 팀이 중요하지 않은 부분(표지, 색칠, 제목 글씨, 그림)에 시간을 쓰고 **필수 항목을 빠뜨리게** 만들기 |
| 방해 요소 | 지원 팀원의 말: "표지가 첫인상이야, 표지부터 예쁘게", "목차 슬라이드는 꼭 있어야 해", "디자인 상 받으면 5점이잖아", "글씨 통일하자, 다시 쓰자" |
| 이벤트 카드 | **디자인 상 예고**: 가장 보기 좋은 PPT에 +5(발표 후 진행자 2 선정). 필수 항목 점수보다 훨씬 작다는 것을 MC가 굳이 말하지 않는다 |
| 제한 시간 | 이벤트 30초 · 제작 7분 · 판정 1분 30초 |
| 판정 기준 | 진행자 2가 필수 5항목 체크. 5개 = 성공, 4개 = 부분 성공, 3개 이하 = 실패 |
| 점수 | 5개 +30, 4개 +20, 3개 +10, 2개 이하 0, 디자인 상 +5. **트롤 비밀 점수**: 다른 팀이 빠뜨린 필수 항목 1개당 +5 |

## 4라운드 · 최종 발표 + 정체 추리 (9분)
| 항목 | 내용 |
|---|---|
| 일반팀 미션 | 1분 발표 + 질문 1개씩 받기(30초). 발표 후 **트롤팀이라고 생각하는 팀**을 투표 |
| 트롤팀 비밀 미션 | 발표 전략을 흔들고(타 팀 견제), 자기 정체를 숨기고 **다른 일반팀이 의심받게** 만들기 |
| 방해 요소 | 날카로운 질문 카드(트롤팀만): "그 자료 몇 년도 거예요?", "예산은 얼마나 들어요?", "학교가 이미 해 본 거 아니에요?". 마지막 협상 때 "우리 지목 안 하면 우리도 너희 찍어 줄게" 같은 거래 |
| 이벤트 카드 | **마지막 협상 타임**(1분): 어떤 거래든 가능. 약속은 지켜도 되고 깨도 된다 |
| 제한 시간 | 협상 1분 · 발표 3팀 × 1분 30초 = 4분 30초 · 추리 투표 1분 · 판정 2분 30초 |
| 판정 기준 | 발표: 진행자 2가 ① 1분 지킴 ② 1R 자료 인용 ③ 해결책이 구체적 — 항목당 10점. 베스트 발표: 각 팀이 자기 팀 말고 1팀에 투표 |
| 점수 | 발표 최대 +30, 베스트 발표 1표당 +10. **추리**: 트롤팀을 맞힌 일반팀 +20, 트롤팀은 맞힌 표 1표당 −15, 일반팀 둘 다 틀리면 트롤팀 +30 |

## 최종 집계 · 결말 (3분)
- 일반팀 = 공개 점수 + 남은 협력 코인 × 5 + 협력 보너스 + 추리 점수
- 트롤팀 = 공개 점수 + **비밀 트롤 점수** + 남은 코인 × 5 + 추리 결과
- 최고점 팀 우승. 트롤팀이 1위면 "트롤팀 승리" 결말, 아니면 "팀플 완주" 결말.
- 진행자 2가 "트롤팀은 일어나 주세요"로 정체 공개, 라운드별 비밀 점수를 화면에 공개.

## 밸런스 메모 (미검증)
트롤팀 비밀 점수 최대치는 1R 60 · 2R 40 · 3R 20 · 4R 30 정도, 일반팀 공개 점수 최대는 라운드당 30~40. 트롤팀이 너무 강하면 비밀 점수를 절반으로, 너무 약하면 추리 감점을 −10으로 줄인다.
