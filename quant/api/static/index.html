◆ 초기 설정 ◆

0 · 투자 성향

여덟 문항으로 시작 설정을 잡습니다. 과학적 진단이 아니라 출발점이고, 언제든 마이페이지에서 바꿀 수 있습니다. 공격형으로 나와도 손절이 사라지거나 하루 손실 한도가 0이 되지는 않습니다 — 성향은 "같은 규칙 안에서 더 크게"까지만 바꿉니다.

1 · 운영자

계정 시스템은 없습니다. 이 봇은 본인 컴퓨터에서 본인 키로만 돕니다. 입력값은 .env(권한 0600, git 제외)에만 저장되며, 저장된 비밀값은 다시 조회할 수 없습니다.

2 · 증권사 · 거래소

쓰실 곳만 켜서 입력하세요. 저장 후 검증을 누르면 실제로 읽기 전용 호출을 한 번 해서 키가 진짜 동작하는지 확인합니다.

3 · 하루 거래 한도

다른 한도들은 전략이 정상일 때를 가정합니다. 이건 고장났을 때를 가정하는 한도라, 브로커 바로 앞에서 실제 주문을 보고 막습니다. 하나만 걸려도 신규 진입이 멈추고, 청산은 절대 막지 않습니다. 0 은 "제한 없음"입니다.
